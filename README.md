## 하지 않는 것들의 목록

1. 신나무 익스텐션즈에서는 『민구홍 매뉴팩처링 운영 지침』을 준수하지 않습니다.
2. 신나무 익스텐션즈에서는 서랍을 채우기 위해 도구를 짓지 않습니다.
3. 신나무 익스텐션즈에서는 AI가 필요 없는 자리에 AI를 붙이지 않습니다.
4. 신나무 익스텐션즈에서는 .ext 확장자를 제안하지 않습니다.
5. 신나무 익스텐션즈에서는 투자자의 도구를 소유하지 않습니다.

6. 신나무 익스텐션즈에서는 신나무 익스텐션즈를 확장하려 하지 않습니다.
7. 신나무 익스텐션즈에서는 하지 않는 것만으로 신나무 익스텐션즈를 정의하지 않습니다.
